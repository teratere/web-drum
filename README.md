# 🥁 Web Drum Studio - 音源合成フィンガードラム＆リズム学習スタジオ

Web Audio APIによる数式リアルタイム音源合成を搭載した、完全クライアントサイド動作のドラム＆リズムスタジオです。  
外部音声ファイル（MP3等）を一切使わず、ゼロ遅延のドラムサウンド、16ステップシーケンサー、そして手足の連動を可視化するドラム初心者向けリズム譜面ビューアを1つのHTMLファイルに統合しています。

> **🌐 Live Demo (本番公開):**  
> ブラウザですぐに叩いて遊べる公開版はこちら 👉 **[https://selfup.net/drum/](https://selfup.net/drum/)**

## 🌟 主な機能 (Features)

### 1. 🥁 ドラムセット (SVG Vector Art)
- **直感的な打楽器イラスト:** バスドラム、スネア、ハイハット、タム、シンバルを精密なSVGで描画
- **打撃アニメーション:** 叩いた瞬間に太鼓が弾み、シンバルがしなるリアルなCSSトランスフォーム演出
- **キー割り当てバッジ:** 各楽器の中心に対応キーが表示され、迷わずキーボード演奏が可能

### 2. ⏹️ フィンガーパッド (MPC Style)
- **ネオン発光レスポンス:** タップまたは打鍵時にビビッドなネオンカラーでフィードバック
- **低レイテンシー設計:** ブラウザ内部のWeb Audio API（サイン波ピッチベンド・バンドパスノイズ合成）により即座に発音

### 3. 🎛️ 16ステップ・リズムシーケンサー
- **先行スケジューリング:** Chris Wilson式 Web Audio Schedulerを採用し、BPMを変更してもリズムが絶対にヨレない高精度エンジン
- **即効プリセット:** 王道8ビート、4つ打ち、16分ファンクパターンをワンタップ呼び出し
- **メトロノーム機能:** ギターやピアノの練習伴奏・テンポキープに最適

### 4. 📖 リズム譜面ビューア (手足の協調トレーニング / 脳トレ)
- **手足の動きを可視化:** 「右手 (Hi-Hat)」「左手 (Snare)」「右足 (Kick)」の手足独立運動をカラーで直感ガイド
- **流れるリズムスコア:** 再生ラインに合わせてリアルタイムにノートが通過し、叩くタイミングを把握

### 5. ⌨️ キーボード割り当てカスタマイズ
- 全パーツのキーバインドをユーザー好みのキー（Space, S, A, F...）に自由に変更可能
- 設定内容はブラウザ（localStorage）に自動保存
